# Changelog

All notable changes to this project will be documented in this file.

## v1 (2026-10-17)

- First release: 21 blocks in 13 groups (menu, hero, text, venue, notice, cards, goodies, perks, teams, steps, pricing, support levels, rates table, programme, gallery, FAQ, contact form, call to action, two footers)
- Blocks appear in the "Add Block" menu, in a "Skyline" group (native components: template.html, style.less, thumb.png)
- Shared stylesheet loaded through a plugin
- Gallery button in the Mobirise top bar as an alternative way to add blocks, with a thumbnail for each block
